## Setup coverage badge

### [Shields.io](https://shields.io) Json Endpoint

[![Coverage badge](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/lahmacunveayran/raisetheempires-tr/python-coverage-comment-action-data/endpoint.json)](https://htmlpreview.github.io/?https://github.com/lahmacunveayran/raisetheempires-tr/blob/python-coverage-comment-action-data/htmlcov/index.html)

Using this one will allow you to [customize](https://shields.io/endpoint) the look of your badge.
It won't work with private repositories. It won't be refreshed more than once per five minutes.
